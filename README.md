# Project Title

MLB Pitch Sequence Predictive Models

## Description

This repository contains MATLAB code for a series of shallow and deep learning models to predict the next pitch from MLB pitchers given the game situation data. The training dataset contains pitch data from 2015 and 2016. The goal is to estimate the next pitch as an output for 2019 data and game situation data as an input.   

## Getting Started

### Dependencies

* Jupyter Notebook
* Python 3.11 or higher
   * numpy
   * pandas as pd
   * scikit-learn
   * matplotlib
   * pymc
   * arviz

### Installing

* Download `src/k_percentage.ipynb` and run in virtual environment containing the dependencies listed above.

### Executing program

* Run each cell in the notebook in order, or execute entire notebook.
